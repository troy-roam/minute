# Changelog

## 0.1.0 — 2026-09-13

- Native two-pane macOS note interface
- Direct rich-text editing with Markdown persistence
- Timestamp-based filenames, note completion, links, and backlinks
- Keyboard navigation and list continuation/indentation behavior
- Recoverable deletion through Trash
- JetBrains Mono typography and custom minute app icon
- Universal Apple Silicon and Intel release packaging
